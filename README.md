# 🌍 Global Sales Dashboard – Power BI Project
# 🔍 Overview
This project presents a dynamic Power BI dashboard offering a global perspective on sales, customer segments, market distribution, and product performance. It enables users to interact with sales data across regions, years, and segments, helping businesses understand their global footprint, identify top customers and products, and recognize loss-driving areas. The visualization is designed to support executive decision-making and sales optimization strategies.
